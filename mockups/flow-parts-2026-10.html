01Key hints: decided

You chose F1. It's shown here on the three screens with different main keys, as the reference for building it.

The rule that comes with it. Main keys are what this screen is for, drawn as caps two spaces apart. The footnote is everything that's always available (esc, ctrl-n new, ctrl-c quit), drawn as dim text at the right edge. When there isn't room, the footnote drops items from its right end; the main keys never shrink, and the row never wraps.

02The drop zone ✓ D2

Decided: D2, dots in the gradient. Every variant has the same three parts in the same places, so the only thing that changes between them is the surface. Each is shown empty, while typing a path, and after pressing 2.

The anatomy, fixed. 1 · The block: numbered modes fused to the drop surface, nothing to type inside it. 2 · The field: its own line below the block, lined up with the block's text. 3 · Suggestions: their own list, a row clear of the field, using the picker's band and strip. While you type, the block steps back so the field leads. 1 2 3 switch mode while the field is empty; once you have typed, they are just characters.

04cWhere commands live, across the whole flow

Every screen from launch to done. The rule: / opens the commands page from the field only (home, or home with a file waiting), and 1 2 3 switch mode on any screen without a text field. Screens that take text (Save to, Name) leave both alone. Click a step to jump to it. The picker and Save to are drawn in the styles decided in the other session, as stand-ins.

04dCommands, on a page of their own

Typing / leaves the home screen for a commands page, so nothing about commands lives on home. Because the tabs are not on this page, the modes are worth listing here: it is the one place that names all three with what they do. Each page is shown after typing /, and after typing /th. Esc goes back to home.

05Working

The moment between pressing ↵ and the receipt. For a big photo or an AVIF this lasts several seconds. Today it's one dim word. A single file has no percentage (invariant 7), so every option shows activity, not progress. The animations below are live.

06Naming the file

07Errors

Captured by saving into a folder without write permission. Today a red card states the problem and the app returns to the empty prompt. The file is unstaged, so to try another folder you start again.
