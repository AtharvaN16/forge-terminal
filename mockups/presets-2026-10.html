WHAT A PRESET CAN HOLD

Every action Forge has today, from src/core/actions. A row keeps its answer as a rule that fits any file of its kind.

Stepswhat you do to a file, in order: Convert to WebP 80, then Resize to 1920 wide. Two or more is what we called a pipeline — the inside word; screens only say “step”.Presetsteps you kept, under a name, with where to save. One step is enough.
StepWorks onWhat the preset keepsNotes
Convertimages, PDFs, Wordthe format and its quality; for a PDF, the pages (all · first) and dpitargets still come from each file (invariant 2)
Compressimages, PDFsby quality, or to a target size (“under 500 KB”)a target size suits presets best
Resizeimagesa width, a height or a % — chosen when saving“longest side” missing
Trim edgesimageson
Crop to shapeimagesthe shape, e.g. 16:9a hand-placed crop is per photo; the preset places it as Forge does unplaced
Sharpen · Boost resolutionimageson · 2× 3× 4×need Boost installed
Remove backgroundimagesonmacOS, needs the extension
RotatePDFs90° right · 180° · 90° left, all pages
SplitPDFsevery page · every N pages“at points I choose” is per document
Extract · Delete · MergePDFs, several files—page numbers are per document; merge is many-in. Later
Setting of the presetValues
nameletters, digits, dashes — so /blog and --preset blog work
toa folder · Ask each time · Same location
filesame name · name-preset (photo-blog.webp)
metadataremoved (default) · kept — --keep-metadata exists

Not steps: colour (makes a palette, not a file); a locked PDF’s password (asked each time, never stored).
