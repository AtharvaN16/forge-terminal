Continue editing: Done is the hub

One idea in three rules, then one flow per situation — doing one more thing, keeping it for next time, using it next time — and the edge cases. Captured from the app, dark, 80 × 24.

The idea

  1. Done is the hub. Continue editing does one more thing to the file you just made, then brings you back to Done.
  2. Done’s strip is the list of what you did — PNG → JPEG 80 → 1920 wide — and Save as preset saves that list.
  3. Every step is redone from the original, so stacking steps never makes the file worse or bigger, and Undo is exact.

Why this shape — from Mobbin

  • Recraft and Magnific: beside the result, a plain list of actions (Remove background, Upscale, Edit image, Save as template). Pick one, it happens to this image, you are back at the result.
  • VSCO: what you did shows as a short list of applied edits with Undo — and that list is the recipe you can reuse.
  • Photoroom: templates explained by what they do — “apply it instantly to multiple images”.

None of them has a separate editor to learn. Rounds one to five each had one (a window, a hub, a list you return to); this round has none.

Decided

  • Tabs: T11 — the tabs’ row is a band, the shown tab lighter; no divider (in flow 3).
  • Presets on home: N5 — p presets in the field once a file is staged, only the presets that fit (in flow 3).

Questions for you

  1. Does the loop in flow 1 read as obvious?
  2. Words to approve: “Continue editing” as the list’s title · “Convert to another format” · “Undo 1920 wide” · “not added · 30 MB” · “✓ webblog” on the button.

F1The happy path

Done → e → pick what → set it → it works → Done again, with the step added to the strip. The same loop every time, and you always land on a screen you have already seen.

You will do the same to more photos later

F2Save the strip as a preset

Save as preset is already on Done. It saves exactly what the strip says — the window shows those steps on top, so you know what you are naming.

Next week, another photo

F3The preset is where the file is

Drop a photo: p presets appears in the field (N5, decided) with the presets that fit it. Or pick it from the Presets tab in Convert to (T11, decided). One ↵ runs every step.

Edge cases — each in the same list, no new screens

F4Undo, can’t, not added

Changed your mind: the list’s first row undoes the last step. A step that cannot apply stays in the list, dim, saying why. A step that needs an on-device model offers it (↵ adds it, then carries on). A step that fails leaves the file and the strip as they were, with the error panel on Done.
