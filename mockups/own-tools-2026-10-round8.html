A tool’s sheet, with hierarchy

Header, a card of facts, one other thing — the same three blocks in every state. Two journeys: getting the tool, and updating it.

How a tool’s sheet reads

  1. Header — the tool’s name and what it gives; on the right, the one button: what ↵ does.
  2. A card of facts — Status, From, Version — the app’s own bordered card, tagged with the tool, as the file card is.
  3. Under the card — the one other thing you can do.

Rules: Forge looks for yours by itself; using yours removes Forge’s copy (it downloads again if yours goes); one key updates either. Only for tools you could have yourself (yt-dlp, ffmpeg); Boost and Remove background keep today’s sheet. Layout borrowed from extension pages — Airtable, Twenty: name, one line, button on the right, labelled facts.
