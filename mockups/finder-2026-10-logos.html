Right-click menu: Finder and Explorer

Right-click a file and run Forge on it. Same items for everyone, on the Mac and on Windows; no settings. Terminal screens are the real app at 80 × 24, edited where this changes them; Finder, Explorer, menus and notifications are drawn.

Decided images: Open Forge · Convert · Compress · Sharpen in Forge · PDFs, video, sound: Open in Forge (staged) · no user options · Windows now · logo: the F on a gradientOpen 5 questionsRound 7

In plain words

  1. Right-click an image: Open Forge, Convert in Forge, Compress in Forge, Sharpen in Forge.
  2. Open Forge just opens the app in a terminal window, without the file.
  3. Open in Forge (the file staged, in its mode) is for PDFs, and for video and sound once those land.
  4. Convert and Compress open Forge in a terminal window with the file already in, one step in. Sharpen just runs, then a notification.
  5. Mac: under Quick Actions. Windows: under Show more options, in a Forge › row.
  6. No settings: it is the same for everyone. Forge adds it on first run.
  7. The logo marks Forge’s rows in both menus.

RULESHow it works underneath

No settingsThe menu is the same for everyone. Sharpen in Forge appears once Boost is installed (from /extensions, as today), and goes if it is removed.
Mac: what an item isA Quick Action: a small .workflow folder in ~/Library/Services that runs one command on the selected files. Forge writes these itself on first run; no Automator, no developer account. Each can carry the logo as its image (to test that Finder shows it in the submenu).
Windows: what an item isRegistry keys under HKEY_CURRENT_USER\Software\Classes, per file type (images, PDFs, folders), so no admin rights. A submenu (WM2) and an icon (forge.ico, shipped with Forge) are both free. Windows 11 shows them only under Show more options; its new menu needs a signed app package.
Finding ForgeNeither system gives a menu item your shell’s PATH. Each item calls a small launcher Forge keeps in its config folder, which records where Node and Forge live and is rewritten on every update.
Opening a windowMac: Terminal and iTerm via AppleScript, Ghostty via open -na Ghostty, whichever you last ran Forge in. Windows: wt.exe, else the old console. Forge opening with files given to it is a small addition: today forge photo.png with no flags does not open the app.
NotificationsMac: a Quick Action can post one, but macOS shows it under the script runner’s name and icon, not Forge’s, unless Forge ships a tiny signed helper app. Windows: Forge registers its own name and logo once (a Start menu shortcut with an app ID), so the toast says Forge.
Several filesMac: one run gets them all. Windows: Explorer starts one process per file, so the launcher gathers them into one run. One notification with totals either way.
Names takenAs in the app: never overwrites, writes photo (1).png.
Privacy prompts (Mac)The first run on Desktop, Documents or Downloads may make macOS ask for access. It needs testing to see which app name it shows.
Uninstalling Forgenpm runs nothing on uninstall, so items would be left behind. An item whose launcher finds no Forge removes itself the next time it is clicked.
