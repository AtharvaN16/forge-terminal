Forge on every computer

Converting, compressing and editing work the same on every Mac and on Windows. What differs is the set of tools that lean on something Apple builds into macOS: transcribe, notes, reading text, remove background, RAW photos and pasting pictures.

Linux can't install Forge at all yet. Most gaps can be closed with small extensions. Only notes can't be matched under the 100 MB limit, and remove background can't either until a smaller model passes your test.

What would close each gap

Paste pictures on Windows 0 MB

Windows can hand the clipboard's picture over by itself (PowerShell). Nothing to download.

Windows

Linux basics 0 MB

Allow Linux in npm, and use Linux's own copy, open and notify commands. Add Linux to the extension list. Right-click works through the file manager's scripts folder.

Linux. The user may need to install wl-clipboard or xclip

HEIC 0.5 MB

The Windows HEIC extension already runs on any system. Publish the same file for Linux.

Linux

Camera RAW ~2 MB

LibRaw is the RAW reader most apps use. It's on npm in a form that runs anywhere (like HEIC's), so one extension covers both.

Windows + Linux

Read text ~21 MB

The small PP-OCR model you already picked. The helper's "read" answer is already shaped for a second reader to slot in.

Windows + Linux

Transcribe 31–57 MB

whisper.cpp with a compressed model (tiny ≈ 31 MB, base ≈ 57 MB). PR #3 downloads the full 142 MB base model, which is over your 100 MB ceiling. Switching it to the compressed one fixes that.

Windows + Linux, maybe Intel Macs

YouTube links ~yt-dlp size

yt-dlp publishes its own Windows and Linux builds. Only worth it once transcribe is there.

Windows + Linux

Boost on Intel Mac and Linux 0 MB / unmeasured

First, run the Intel build that already exists on a real Intel Mac. Apple's CoreML may use its graphics chip, and that could be fast enough. If not, Real-ESRGAN also has a build that runs on any graphics card (Vulkan) and covers Linux too. Its size hasn't been measured.

Intel Mac + Linux

ffmpeg on a Mac without Homebrew unmeasured

The video extension's build script is written but has never been run or published (it needs your OK to push the tag). Windows and Linux get ffmpeg easily from winget or apt.

Mac

Notes too big

A local model that writes decent notes is hundreds of MB. Turn notes off on Windows, Linux and Intel, as Apple silicon Macs without Apple Intelligence already do.

stays Apple silicon only

Small models failed your quality test. A compressed IS-Net (≈ 43 MB) is the one left to try against the 7 test images.

Suggested order

  1. Paste pictures on Windows — no download, closes a gap Windows users hit daily
  2. RAW extension — 2 MB, Windows and Linux at once
  3. Read-text extension — 21 MB, the code is ready for it
  4. Transcribe via whisper — take PR #3, swap in the 31–57 MB model, add Windows
  5. Try the Boost build on an Intel Mac — borrow one; nothing to build
  6. Linux support — your call whether to support it at all; the work is mostly swapping commands
