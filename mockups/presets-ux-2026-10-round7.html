Continue editing: showing the chain

Done stays the hub. What changes is how the chain of steps is drawn — five directions, each at the same five moments, so you can see whether it reads as one process you can save.

Locked from round six

  1. Done is the hub. Continue editing does one more thing to the file and brings you back to Done.
  2. Done shows what you did; Save as preset saves exactly that.
  3. Every step is redone from the original.

The one open question

You said nothing makes it feel like a multi-step process — so saving doesn’t read as “these steps, in order”. Each direction below draws the chain differently, at the same five moments: 1 Done after the convert · 2 choosing step 2 · 3 Done after step 2 · 4 saving · 5 the preset running on another photo.

The same five moments in each — only how the chain is drawn changes

C1A chain of links, with a slot for the next

MY PICK. Done’s strip becomes the chain itself: PNG ─▸ [JPEG 80] ─▸ [1920 wide] ─▸ [ + ]. The empty + slot at the end is the next link — what e fills. Choosing a step shows the chain with a ? where it will go; saving shows the same chain; running lights the links one by one.

C2Numbered steps, as a recipe

Done lists the steps in order, numbered, each with the size it leaves — 1 Convert to JPEG 80, 2 Resize to 1920 wide, 3 + Continue editing. The bar shrinks to three rows to make room. Choosing is “Step 2”; saving lists the numbered steps; running ticks them off.

C3A timeline of the file

Each version of the file is a dot on a line, like a history: the original, after JPEG 80, after 1920 wide — each with its size and a bar for it, so you see the file shrink as the chain grows. The next dot is hollow. It replaces Done’s bar.

C4A recipe card, from the first step

From the first step, Done carries a small card at its right: Recipe · 2 steps, numbered, + next. It reads like a cart you are filling — and Save as preset is saving that card.

C5A stepper

The classic multi-step progress line above Done’s strip: ① JPEG 80 ✓ ── ② 1920 wide ✓ ── ③ next. Familiar from checkouts and sign-ups; saving shows the same stepper; running fills it.
