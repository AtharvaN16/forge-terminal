Notes

  • I stopped after the first run. It pushed this Mac's swap to 3.2 GB, past your 3 GB line, and its peak was over the 6 GB line.
  • The speed may be slower than it should be, because the Mac was short of memory while it ran.
  • The 80 MB was made by compressing the model, then storing its big lookup tables in half the space with no change to the answers. Compressing alone gave 112 MB, over the limit.
  • The half-precision version would be about 112 MB, so it is over the limit too and I skipped it. I didn't try any other model.
  • The code is MIT. The model learned from public research photo sets, and I didn't read their terms.
Keep remove background Mac-only for now. BiRefNet-lite is the first model that is good enough, but a Windows or Linux laptop with 8 GB would likely freeze on it. It is worth one more round aimed only at memory (smaller working size, and ONNX Runtime's memory settings). If a run stays under about 3 GB and still looks like this, ship it on Windows and Linux.
