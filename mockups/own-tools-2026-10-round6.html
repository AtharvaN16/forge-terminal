/extensions, one tool at a time

Check this Mac moves onto each tool’s own sheet. Three flows: Forge didn’t find yours but you have it; you don’t; you have both.

How it works, per tool

  1. Forge looks by itself when you open a tool in /extensions. Found: it uses yours and says so. Nothing to press.
  2. Not found: the sheet asks “Do you already have this?” — c checks this Mac (a spinner while it looks).
  3. Found: ↵ use it. Still not found: drop the file in, or type its path.
  4. Both copies: pick which one is used; x deletes Forge’s.

Only on tools you could have yourself — YouTube links (yt-dlp), Video and audio (ffmpeg); drawn with YouTube links. Boost resolution and Remove background are Forge’s own and keep today’s sheet. Everything else from round five stands.
