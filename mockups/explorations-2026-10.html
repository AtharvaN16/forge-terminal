Explorations, round 3: the picker

The question screen and the option rows were two halves of one thing, and they're now one component, the picker. Two designs won. The band with a strip (B2) answers every question that has a fixed set of choices. Save to gets the search box with its options in a frame (G): you can pick a place, type to filter, type a path, or drag a file or folder onto the input. Section 02 plays the whole flow using both.

01The picker: band for choices, search for Save to

The band runs on Format and PDF pages here; switch between them to see it take the PDF mode's colour. Save to uses the search box. It filters places as you type, and at the end of the loop a file is dragged onto the input to save next to that file.

  1. Sizes are measured, never estimated. Only the highlighted format is encoded. Moving away cancels the encode, and results are cached.
  2. The mode's colour does the highlighting. It's cyan here and coral for PDF. Switch to "PDF pages" to see it.
  3. Answers collapse into a ✓ trail above the next question.
