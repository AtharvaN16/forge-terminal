The More button, and after a copy

First the button types Forge already has, then the More button drawn only as one of them, then the copy message.

Tailwind: in the app it is only the name of the default steps (Tailwind 50 – 950, on the steps line). Copying colours as code tokens (CSS variables, a Tailwind config, JSON) was part of the export window that was dropped on 2026-10-13, and the colour spec lists CSS variables as out of scope. The command line can print a scale as JSON (forge scale #6579FD --json), but that is data, not tokens.
