The More button, and after a copy

Two questions, each with options to rate. Everything else is round 5’s flow, unchanged.

What the copies are: ↵ copies the hex as text. c copy all copies an SVG card: Figma turns it into swatches, and in code it is SVG markup. It is not design tokens (CSS variables or JSON). Those would be a new copy, and only if you want one.
