Presets and Continue editing: what nobody got

Your friends could not tell what Continue editing does, watched Compress spin with no word of what was happening, and had no way to find a saved preset again. Five questions, one tab each; every option is drawn with the app’s own pieces over the real Done.

Status

  • Fixed (b91c125): the spinner that never stopped; ↵ while working; errors cut off at the window’s edge; Compress making a file bigger; Compress refusing a PNG; a /compress result losing its compression when edited or saved.
  • Elsewhere: Done’s own buttons (Save as preset, Continue editing, Home…) are on the done-next page, so nothing here redraws Done.

OPTIONS — pick one or more: where a saved preset is found again

A1Each preset is a / command

MY PICK, with A2. The / menu gets a Presets section first: /webblog, its steps where a command’s words go. Choosing it makes the preset the mode — its steps under the tabs — and the next file dropped goes straight through it. The name rule (letters, digits, dashes) was made for this: /webblog here, forge --preset webblog in a shell.

A2Presets first in Convert to

MY PICK, with A1. Where you already are when you drop the next photo: saved presets sit above the formats, each with its steps and the size it would make, measured like a format’s. One ↵ runs all the steps. Found without knowing it exists.

A3A presets tab on home

A seventh tab, 7 presets: the list where the field is, the drop zone above. Drop a file on the lit one. Also where a preset is deleted (⌫). Costs a tab for something many people will have none of, and seven tabs only just fit at 80 columns (the gaps tighten to two cells).

A4Each preset in Finder’s right-click

Forge already installs Quick Actions (/right-click). Each preset becomes one more: right-click photos in Finder, Forge: webblog, done — Forge never opened. Works with A1–A3, not instead of them.

OPTIONS — what Continue editing shows. Its shape (W2: one window, a row per operation, ● / ○, a row’s window under it) stays unless you pick B4

B0Today, after the fixes

For comparison. Opens with the cursor on Compress; nine rows; four of them cannot be used on this photo.

B1The steps on the window’s first line

MY PICK. PNG → JPEG 80 → under 300 KB, in Done’s strip style, grows as you select rows. Says what ● means without a word of help: the dots are the steps. It is also exactly what Save as preset will keep.

B2Only what applies to this photo

Trim (nothing to trim) is gone; the three models that are not added fold into one last row that opens the extension offer. Six rows instead of nine, none of them dead.

B3The foot says before → after

What this edit did to the file you had: 708 KB → 297 KB, 58% smaller. Today’s foot compares with the 16 MB original, so every step looks like a big saving — even one that made the file bigger.

B4Only your steps, and + Add a step (reopens W2)

Drawn because nobody knew where to start in nine rows. The window lists only the steps you have; + Add a step opens the rest under it. Reopens the decided W2, so only if the friend test changes your mind.

OPTIONS — what the window says while a step runs (here Compress on a 16 MB photo, a few seconds)

C1Today, after the fixes

For comparison: the row spins, the foot says Compressing, a clock after 3 s. Nothing says the file on disk is untouched or how far along it is.

C2Says how far: try 3 of 8

MY PICK. A size search encodes at most 8 times and Forge knows which try it is on, so this is a fact, not a made-up bar (invariant 7 allows it). Long waits stop feeling stuck.

C3The old file stays until the new one lands

The foot keeps the file you have, dimmed, with an arrow to the one being made. Says without words that nothing is lost yet; esc stop is on the key row.

C4The window waits with you

Every row but the working one goes faint and the keys shrink to esc stop: plainly busy, plainly stoppable. Costs the ability to queue the next change while one runs.

OPTIONS — saving what you just did, from where you are

D1p inside the window

MY PICK, with D2. The edit window’s keys gain p save as preset, the same key as on Done. The Save as preset window opens over the edit window; esc goes back to it.

D2The save window shows what it keeps

MY PICK, with D1. The steps on the save window’s first line, above the name: you name something you can see. Today the window covers them.

D3Asked once, on ↵

Leaving the window with new steps asks once whether to keep them; ↵ again just leaves. Hard to miss — but a question every time you edit, which may wear.

D4The saved line says how to use it

With A1: ✓ saved as /webblog — the command is the name, so the confirmation teaches where it lives. (Done’s foot itself is being redesigned on the done-next page; this is only the words.)

OPTIONS — Compress and Quality both set how small the file gets; today they are two rows that silently fight

E1One Quality row, compress mode’s two ways

The Compress row goes. Quality’s window offers By quality or To a target size, exactly as compress mode asks. One row, one answer.

E2Both rows, Quality says “up to 80”

MY PICK — smallest change, keeps W2. Since b91c125 a target size never goes above the Quality row; with Compress on, Quality’s value reads up to 80 so the link is visible.

E3Quality holds either answer, in the row

No window: the lit Quality row shows 80 · under ___ KB; typing digits fills the size, tab goes back to the slider. Fast, but two answers in one row is a lot to read.
